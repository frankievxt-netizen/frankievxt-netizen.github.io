Channel Studio

Channel Studio is a private publishing tool run by one independent creator. It uploads the creator's own finished videos, titles, descriptions and thumbnails to the creator's own YouTube channels, and schedules when they go public. It is not offered to the public and no one else can sign in to it.

The tool runs on the creator's own computer. It uses the YouTube Data API only for the creator's channels listed below:

  • Doomsday Math
  • Atlas of Time
  • Somewhere to Sleep
  • 10,000 Tries
  • Milo's Brick World
  • Wild Mind
  • Quiet Psychology
  • Run It 100 Years
